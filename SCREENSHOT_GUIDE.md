# Screenshot Checklist

1. **Main Overview**
   - M01, M02, M03 visible
   - At least one motor running
   - No active fault for the clean hero image

2. **Motor Detail — Healthy Running**
   - RUN COMMAND and RUNNING green
   - READY / E-STOP OK / THERMAL OK healthy
   - Fault indicators inactive

3. **Motor Detail — Fault**
   - Prefer Feedback Fault or Thermal Fault
   - Relevant fault indicator red

4. **Alarm Center**
   - Show one active alarm

5. **Alarm History**
   - Show cleared alarms with timestamps and state changes

6. **Optional Engineering Screenshot**
   - Motor Control FB in TIA Portal, or
   - Device configuration showing CPU + DI + DQ modules

## Presentation Tips
- Keep the same zoom level.
- Crop unrelated Windows/TIA/browser chrome where possible.
- Use consistent M01/M02/M03 naming.
- Put the clean Main Overview image first on GitHub and LinkedIn.
